# TechCo Facilities Explorer

An interactive companion to the FY27 facilities forecast in [`../writeup.md`](../writeup.md). Drag the levers, get live three-statement impact for the FY27 capacity expansion decision.

## What it answers

The static writeup answers _"what does the FY27 plan cost?"_ This dashboard answers the harder follow-up: **_"what are the consequences of the plausible alternatives?"_**

Six levers — space density (sqft/HC), HC variance, leasehold buildout cost, snacks budget, F&F per seat, and an `expand` toggle — feed a TypeScript port of the parent project's FY27 forecast. Each lever change redraws four KPI cards (Gross facilities P&L, Total capex, Net cash change, OpEx per FTE), a driver waterfall (FY26 gross → FY27 gross with bars for Rent, Sqft other, Snacks, HC-driven OPEX, Fixed, Depreciation), a 3-statement walk emphasizing gross P&L as the headline, and a 16-line lever-reactive bucket-detail table. Three preset buttons (Hold the line / Expand to plan / Invest ahead) snap the levers to canonical scenarios.

**Allocations are excluded from every total.** Internal allocations (~81% of gross, recovered from internal customers) are intercompany reclassifications — they shift cost between departments without changing the corporation's total cash, BS, or RE impact. The dashboard's KPI cards, BS movements, CF formulas, waterfall end-anchor, and Δ Retained Earnings line all use **gross facilities P&L** as the headline. See `../writeup.md` Executive Summary framing note for the rationale.

URL query params encode current scenario state, so sharing a link preserves the scenario.

## Architecture, briefly

- **Next.js 16 (App Router) + React 19 + TypeScript.** One route, no backend. Numbers are computed client-side from a frozen JSON snapshot.
- **Math engine** (`lib/compute.ts`) — pure function `computeScenario(base, levers)`. Implements lever multipliers against the parent project's Phase 4 default monthly cells. At expand-to-plan default levers all multipliers = 1.0, so reconciliation to the writeup's anchors (gross **$35.74M**, capex **$13.44M**, net cash **−$42.93M**, expansion sqft **+34,800**) is **guaranteed by construction** (down to ~$1K rounding). See `PLAN.md` §5.2 + `POSTMORTEM.md` for the architecture rationale.
- **Data** (`data/base-case.json`) — generated by `scripts/generate_base_case.py` from the parent project's CSVs (`assumptions/`, `fy26_runrate/`, `fy27_forecast/`). Re-run the generator if any upstream phase output changes.
- **Charting** — hand-rolled SVG with `d3-scale` for axes. No Recharts (defaults fight the design). ~210 lines.
- **Design** — Plex Reorg tokens lifted from `../design/colors_and_type.css`: IBM Plex Sans + Mono, hairline borders, indigo accent, oxblood/sage delta semantics, no SVG icons or emoji, mono tabular numerals, true minus signs (U+2212).
- **Polish layer** — `tabular-nums` on `:root`, font smoothing, interruptible CSS transitions only (no `transition: all`), 40×40 minimum hit areas, `scale(0.96)` on press, first-load stagger via CSS `animation-delay` utility classes, `prefers-reduced-motion` guard.

## URL parameters

Shareable scenario links. Defaults are not emitted to keep URLs short.

| Param | Lever | Range | Default |
|---|---|---|---|
| `d`  | Space density (sqft/HC) | 100–250 | 150 |
| `hc` | HC variance (% as integer) | -15 to +15 | 0 |
| `b`  | Buildout cost ($/sqft) | 200–600 | 350 |
| `s`  | Snacks ($/HC/yr) | 3000–15000 | 14000 |
| `f`  | F&F per seat ($) | 2000–5000 | 3399 |
| `e`  | Expand toggle (0 = hold-the-line, 1 = expand) | 0 / 1 | 0 |

Examples:

- `/` — Hold-the-line (the new default; no expansion, sf/HC drops below 150)
- `/?e=1` — Expand-to-plan (the parent writeup's base case: 34,800 sqft expansion, $13.4M capex)
- `/?d=200&b=500&f=4500&e=1` — Invest-ahead (loose density + premium buildout — capex blows out to ~$36M, well above the single-lever ceiling, illustrating why combining levers matters)

## Verification

`npm test` runs 38 tests:

- **Anchor reconciliation** (6) against the rebuilt writeup's headline numbers (gross P&L $35.74M, net pretax $6.72M, capex $13.44M, net cash $−42.93M, ΔFA Net $9.42M, expansion sqft +34,800).
- **Hold-the-line scenario tests** (5) — defaults are hold-the-line; expand-to-plan tested as a preset; cash improves ~$16M when capex collapses.
- **Bucket-detail table tests** (9) — bucket count / canonical order / sum-to-gross reconciliation / lever isolation per family / FacilitiesPayroll regression test for the latent bug fix.
- **Waterfall reconciliation** (2) — start + Σ deltas = end at FY27 gross; sum reconciles to `pnl.gross`.
- **Preset smoke tests** (3) — hold-the-line capex collapses; invest-ahead capex blows out; HC-10% modest P&L move.
- **Directional sanity** (3) — higher density → more capex; higher snacks → higher gross; higher F&F → capex moves more than P&L.
- **URL round-trip** (9) — preset encoding, hcVariance integer percent, invalid params fall back, defaults stay empty, expand toggle round-trip, hold-the-line preset = defaults.

## Known simplifications

Documented in PLAN.md §5.2 and worth knowing:

1. **Allocations as ratio × gross.** The parent's per-bucket allocation logic is approximated as `−effectiveAllocationRatio × gross` (~81%, calibrated against Phase 7 corrected gross). The result is computed for traceability but **not used** in any KPI card, BS formula, or CF formula — allocations are excluded from totals per the framing convention.
2. **Bucket-detail table uses family-level proportional scaling.** The 16 individual buckets within a driver family (e.g., Utilities + Maintenance + Insurance + FacilitiesPayroll all in "Sqft × inflation") are computed as `defaultBucket × familyLevered/familyDefault`. This is exact when all buckets within the family share the same per-office distribution; in practice it's a small approximation under non-default levers (per-bucket values may drift from per-office-exact totals by a few percent). The waterfall and 3-stmt walk use the exact per-office summed values; only the bucket-detail table relies on the proportion.
3. **France + Germany small-office actuals** roll into the unallocated bucket (held flat under all levers). They appear in Feb–Mar 2026 transactions but aren't in the parent's HC/sqft plan.
4. **Existing depreciation uses Phase 5 reclassified run-rate** ($3.01M annual: LHI $1.63M / FF $1.03M / OE $0.35M), not the FY26-unit-rate sum ($2.84M).
